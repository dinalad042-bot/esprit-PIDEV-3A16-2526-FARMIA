# FARMIA - Smart Agriculture Platform (Web Version)

## Description

FARMIA is an intelligent agriculture management platform designed to help farmers monitor and optimize their daily activities through modern technologies and AI-powered services.

The platform enables users to manage farms, crops, animals, agricultural equipment, and expert consultations while improving productivity and reducing losses.

## Technologies Used

* Symfony 6.4
* PHP 8.2
* MySQL
* REST APIs
* Python AI Services
* OpenCV
* JavaScript
* HTML5 / CSS3

## Main Features

* Secure Authentication System
* Email Verification Workflow
* User & Role Management
* Farm Management
* Animal & Crop Monitoring
* Smart Alerts & Notifications
* Expert Analysis & Recommendations
* AI Chatbot Assistance
* Product & Equipment Marketplace
* Address Autocomplete Integration
* Facial Recognition Authentication

## Installation

### Clone the Repository

```bash
git clone <repository-link>
```

### Backend Setup

```bash
composer install
```

### Configure Environment

Update the `.env` file with your database configuration.

### Run Migrations

```bash
php bin/console doctrine:migrations:migrate
```

### Start the Symfony Server

```bash
symfony server:start
```
